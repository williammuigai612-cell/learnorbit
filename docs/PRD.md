# LearnOrbit V1 — Product Requirements Document

## 1. Vision
LearnOrbit is a social learning platform where people can discover, create, share and discuss academic learning content.

The experience should combine the discoverability and creator model of a video/social platform with tools specifically designed for academic learning and examinations.

## 2. Target Users
### Students
- Discover educational videos and Shorts
- Follow teachers and educational creators
- Watch lessons
- Save useful content
- Access PDFs and past papers
- Practice quizzes and exam preparation
- Interact with other learners

### Teachers / Educational Creators
- Create a channel
- Publish educational videos
- Publish Shorts
- Share academic resources
- Build an audience
- Interact with learners

### Schools / Institutions
- Create an institutional channel
- Publish educational content and resources
- Build a trusted academic presence

### Parents
Planned for V1/V1.x:
- Connect to a child's learning activity
- Support learning and exam preparation

## 3. Core V1 Features
1. Authentication and user profiles
2. Teacher/school/creator channels
3. Channel following/subscriptions
4. Long-form educational videos
5. Educational Shorts
6. Home/discovery feed
7. Likes
8. Comments
9. Saves/bookmarks
10. Educational posts/content metadata
11. PDFs and academic resources
12. Past papers
13. Quizzes
14. Exam preparation
15. Search
16. Basic notifications
17. Basic reporting/moderation
18. Basic learning/progress information

## 4. Content Organization
Content should support academic context where practical:
- Subject
- Topic
- Level/class/course
- Institution or curriculum context
- Exam/resource type

The initial implementation should remain flexible enough to support Kenyan academic content without hard-coding the platform to one examination body.

## 5. V1 Non-Goals
Not required for the first usable V1:
- Live streaming
- Complex recommendation/ML ranking
- Creator monetization
- Advertising platform
- Advanced parental controls
- Full enterprise school management system
- Messaging/chat system unless required for core community interaction
- Native mobile apps

## 6. Success Criteria
A student should be able to:
1. Create an account.
2. Discover a teacher/channel.
3. Follow the channel.
4. Watch an educational video.
5. Watch a Short.
6. Like/comment/save content.
7. Find an academic PDF or past paper.
8. Take a quiz or exam-preparation activity.

A teacher should be able to:
1. Create/manage a channel.
2. Publish educational content.
3. Publish Shorts.
4. Attach relevant academic resources.
5. See basic engagement information.

## 7. Product Principle
Learning comes first. Social features should improve discovery, motivation and interaction without turning the product into a generic social network.
